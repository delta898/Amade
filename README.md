# Amade

Amade's production branch is `main`. It is intentionally kept to this README while the template catalog and specifications are being developed and validated on [`dev`](https://github.com/delta898/Amade/tree/dev).

## Development

The active catalog, resource specifications, and versioned template packages are on [`dev`](https://github.com/delta898/Amade/tree/dev). See the [Amade resource specification](https://github.com/delta898/Amade/blob/dev/amade/spec/README.md) for the catalog format, package rules, and development-to-production promotion process.

BlogGenius local/development builds read the catalog from `dev`. BlogGenius production reads from `main`; production resources will appear there only after they have been reviewed and promoted.
